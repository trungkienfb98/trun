# Content and caption rules

## Verbatim mode

Preserve every word, punctuation mark, capitalization choice, and sequence from the approved source. Change line breaks only. Never silently shorten text to make it fit. If it is too dense, reduce size within a readable limit, adjust spacing, or ask whether the user wants an adapted version.

## Adapted mode

Rewrite only after authorization. Preserve factual meaning and avoid adding personal experience, results, revenue, credentials, or endorsements the user did not provide.

## New draft mode

Choose a formula supported by channel analysis: comparison, roundup, tutorial, AIDA, mistakes, before/after, or reasoned opinion. Present the draft before rendering when it contains new claims or a new brand voice.

Use paths relative to the workspace when possible.

## Caption

Write a complete caption distinct from the visual hierarchy. Lead with the result, tension, or discovery. Add useful context, examples, or steps. End with an open observation or natural question when direct CTA is disabled. Respect hashtag and CTA settings. Do not claim virality, product performance, or personal use without evidence.
